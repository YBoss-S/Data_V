# Unlocking Student Potential — Dashboard

แดชบอร์ด Streamlit สำหรับวิเคราะห์ผลการเรียน (GPA) การเข้าร่วมกิจกรรมเสริมหลักสูตร ช่องว่างการรับรู้ทักษะ (Perception Gap)
พัฒนาการทักษะ และทักษะที่ปรากฏในประกาศงาน ใช้ประกอบรายวิชา 01219482 การอธิบายข้อมูลด้วยภาพ

**กลุ่มผู้ใช้:** นิสิต (Student) · อาจารย์ผู้สอน (Instructor) · ผู้ประกอบการ (Employer) — เลือกมุมมองได้ที่ Sidebar
(มุมมองเปลี่ยนเฉพาะข้อเสนอแนะท้ายหน้า ตัวเลขและกราฟเหมือนกันทุกมุมมอง)

## โครงสร้างไฟล์

```text
data_viz_project/
├── .streamlit/config.toml            # Theme
├── data/
│   ├── Student_performance_data.csv
│   └── job_market_skills_dataset.csv
├── tests/
│   ├── test_data_loader.py           # unit test ของฟังก์ชันคำนวณและกราฟ
│   └── test_app.py                   # ทดสอบแอปด้วย Streamlit AppTest
├── app.py                            # หน้า UI (Streamlit) และการแคช
├── data_loader.py                    # โหลด ตรวจสอบ คำนวณ (ไม่พึ่ง Streamlit)  [เพิ่มใหม่]
├── charts.py                         # ฟังก์ชันสร้างกราฟ Plotly              [เพิ่มใหม่]
├── requirements.txt
├── requirements-dev.txt              # เพิ่ม pytest สำหรับรันชุดทดสอบ
└── README.md
```

`data_loader.py` และ `charts.py` แยกออกมาเพื่อให้ทดสอบโดยไม่ต้องเปิดแอป และไม่ปะปนกับโค้ด UI

> ไฟล์นิสิตที่ได้รับมาชื่อ `Student_performance_data__.csv` (ขีดล่างสองตัวท้ายชื่อ)
> ถูกเปลี่ยนชื่อเป็น `Student_performance_data.csv` ตามโครงสร้างที่กำหนด เนื้อหาไม่ถูกแก้ไข

## ติดตั้งและรัน (Windows PowerShell)

```powershell
cd data_viz_project
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

รันชุดทดสอบ:

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest
```

## Dataset

### `data/Student_performance_data.csv` (2,392 แถว)
คอลัมน์ที่แอป **ต้องใช้**: `StudentID`, `GPA` (0.0–4.0), `Extracurricular` (0/1), `Sports` (0/1), `Music` (0/1),
`Volunteering` (0/1), `Absences`, `StudyTimeWeekly`
คอลัมน์อื่นในไฟล์ (`Age`, `Gender`, `Ethnicity`, `ParentalEducation`, `Tutoring`, `ParentalSupport`, `GradeClass`)
ไม่ถูกนำมาวิเคราะห์ ยกเว้น `Age` (แสดงช่วงอายุ) และ `GradeClass` (ตรวจคุณภาพข้อมูลเท่านั้น)

### `data/job_market_skills_dataset.csv` (1,000 แถว)
คอลัมน์ที่ **ต้องใช้**: `job_title`, `company`, `location`, `category`, `created_date`, `description`, `skills`

### ข้อมูล Benchmark / จำลอง
คะแนน Perception Gap (นิสิต vs ตลาด) และคะแนน Skill Progression 3 Phase **ไม่มีไฟล์ต้นทาง**
เป็นค่าที่กำหนดไว้ในโค้ดเดิมของโปรเจกต์ (อยู่ใน `data_loader.py` ส่วน Benchmark) แดชบอร์ดติดป้ายกำกับไว้ทุกจุด
หากมีผลสำรวจจริง ให้แทนที่ฟังก์ชัน `get_perception_benchmark()` และ `get_progression_benchmark()`

## KPI และวิธีคำนวณ

| KPI | วิธีคำนวณ | ได้รับผลจากตัวกรอง |
|---|---|---|
| นิสิตที่ผ่านตัวกรอง | จำนวนแถวหลังกรอง GPA และกิจกรรม | ใช่ |
| GPA เฉลี่ย | ค่าเฉลี่ย `GPA` ของแถวที่ผ่านตัวกรอง | ใช่ |
| ผู้เข้าร่วมกิจกรรมฯ | นิสิตที่ `Extracurricular = 1` ÷ นิสิตที่ผ่านตัวกรอง | ใช่ |
| Perception Gap สูงสุด | Gap = คะแนนนิสิต − คะแนนตลาด แล้วเลือกค่าติดลบมากสุด (Benchmark) | ไม่ |
| ร้อยละทักษะเทคนิค | จำนวนประกาศที่คอลัมน์ `skills` มีทักษะนั้น ÷ ฐาน (ทุกประกาศ หรือเฉพาะที่ระบุทักษะ เลือกได้) | ไม่ |
| ร้อยละ Soft Skill | จำนวนประกาศที่ `description` ตรงกับ keyword (regex ขอบเขตคำ) ÷ ทุกประกาศ | ไม่ |
| ความต่าง GPA | ค่าเฉลี่ย GPA กลุ่มเข้าร่วม − ไม่เข้าร่วม พร้อมช่วงความเชื่อมั่น 95% (Welch ประมาณด้วย z = 1.96) แสดงเมื่อทั้งสองกลุ่ม ≥ 30 คน | ใช่ |

## ข้อจำกัดของข้อมูลและการตีความ

- **ความสัมพันธ์ ไม่ใช่สาเหตุ:** ข้อมูลนิสิตเป็นข้อมูลเชิงสังเกต GPA ที่ต่างกันระหว่างกลุ่มกิจกรรมไม่ได้พิสูจน์ว่ากิจกรรมทำให้ GPA สูงขึ้น
  `Absences` มีสหสัมพันธ์กับ GPA สูงมาก (r ≈ −0.92 ทั้งชุด) จึงเป็นตัวแปรร่วมที่ควรพิจารณา
- **ช่วงอายุ 15–18 ปี** เป็นวัยมัธยมศึกษา ไม่ใช่นิสิตระดับอุดมศึกษา และไม่มีคอลัมน์วันที่ จึงระบุช่วงเวลาของข้อมูลนิสิตไม่ได้
- **`GradeClass`** สัมพันธ์กับ GPA ไม่เด็ดขาด (Spearman ≈ −0.82 ช่วง GPA ของแต่ละคลาสทับซ้อนกันมาก)
  และไม่มีคำอธิบายรหัส จึงไม่ใช้
- **`Extracurricular` เป็นธงแยกจาก `Sports`/`Music`/`Volunteering`** นิยามของแต่ละคอลัมน์ไม่มีเอกสารอธิบาย
- **ประกาศงาน:** 594 จาก 1,000 ประกาศไม่มีข้อมูลในคอลัมน์ `skills` ส่วนใหญ่เป็นสายข้อมูล/IT (925 ประกาศ)
  และสถานที่ส่วนใหญ่อยู่ในอินเดีย จึงอาจไม่แทนตลาดแรงงานไทย มี 55 ประกาศที่ตำแหน่ง/บริษัท/คำอธิบายซ้ำกัน (รวมอยู่ในการคำนวณ ไม่ได้ลบ)
  คอลัมน์ `avg_salary` ว่างทั้งหมด ประกาศ 71% สร้างในเดือน 2025-12
- **Soft Skill จากคำอธิบายงาน** เป็นการค้นคำ ไม่ใช่การจำแนกทักษะจริง และคำอธิบาย 97% ถูกตัดที่ 500 ตัวอักษร ค่าที่ได้จึงเป็นค่าประมาณขั้นต่ำ
- **การทำความสะอาดข้อมูล:** แอปไม่แก้ค่าหรือเปลี่ยนชื่อคอลัมน์ หากพบแถวที่ใช้ไม่ได้ (ค่าว่าง ไม่ใช่ตัวเลข GPA นอก 0–4 ธงกิจกรรมที่ไม่ใช่ 0/1)
  จะตัดออกและแจ้งจำนวนกับเหตุผลที่แท็บ "คุณภาพข้อมูล" กับข้อมูลชุดปัจจุบันไม่มีแถวถูกตัด

## Deploy (Streamlit Community Cloud)

1. อัปโหลดโฟลเดอร์ทั้งหมด (รวม `data/` และ `.streamlit/`) ขึ้น GitHub
2. ที่ https://share.streamlit.io เลือก repository, branch และตั้ง Main file path เป็น `app.py`
3. Cloud ติดตั้งแพ็กเกจจาก `requirements.txt` ให้อัตโนมัติ

## แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ข้อความ "ไม่พบไฟล์ ... ที่ตำแหน่ง ..." (`FileNotFoundError` เดิม) | วางไฟล์ CSV ไว้ใน `data/` ให้ชื่อตรงตามโครงสร้างด้านบน (ตัวพิมพ์ตรงทุกตัว) แอปอ้างอิงตำแหน่งจาก `__file__` จึงรันจากโฟลเดอร์ใดก็ได้ |
| `ModuleNotFoundError: No module named 'streamlit'` (หรือ plotly/pandas) | รัน `python -m pip install -r requirements.txt` ด้วย Python ตัวเดียวกับที่ใช้รัน `python -m streamlit run app.py` |
| ข้อความ "ขาดคอลัมน์ที่จำเป็น: ..." | ตรวจชื่อคอลัมน์ในไฟล์ให้ตรงกับรายการในหัวข้อ Dataset (แอปไม่เปลี่ยนชื่อคอลัมน์ให้อัตโนมัติ) |
| ตัวเลขไม่ตรงกับไฟล์ | ตรวจตัวกรองใน Sidebar แล้วกด Reset Filters ดูแท็บ "คุณภาพข้อมูล" ว่ามีแถวถูกตัดหรือไม่ หากแก้ไฟล์ CSV แล้ว แอปจะโหลดใหม่เองเมื่อเวลาแก้ไขไฟล์เปลี่ยน |
